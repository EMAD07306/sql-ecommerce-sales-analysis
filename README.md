# SQL Ecommerce Sales Analysis

## Project Overview

This project analyzes ecommerce sales data using SQL to identify sales trends, revenue performance, top-selling products, and business insights.

The goal of this project is to demonstrate SQL querying, KPI reporting, and business analytics skills commonly used in ecommerce and operational reporting environments.

---

## Tools Used

* SQL
* Excel
* Power BI

---

## Business Questions Analyzed

* What are the top-selling products?
* Which months generated the highest revenue?
* Which product categories performed best?
* What sales trends can be identified?
* How can data support business decision making?
